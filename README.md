# signal-terminal

**A playable terminal in the fictional hallway archive.** Tune channels, decode a hexadecimal transmission, and turn the camera to recover the missing frame.

**[Open the live terminal](https://user225314.github.io/signal-terminal/)**

The page is a single self-contained [`index.html`](index.html). It needs no build, install, account, or external API. Progress is stored only in your browser's local storage; use **Reset case** to start over. It does not count visitors.

If you want the full story, start at [door-is-open](https://github.com/User225314/door-is-open), continue to [the-eighth-door](https://github.com/User225314/the-eighth-door), then inspect [operator-unknown](https://github.com/User225314/operator-unknown). The terminal is playable by itself too.

<sub>Fictional interactive story. No real people, places, or emergencies are represented.</sub>
